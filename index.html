Semana 2 - Git y GitHub

Control de versiones y trabajo colaborativo

1. ¿Qué son Git y GitHub?

Git

Git es una herramienta de control de versiones que permite registrar los cambios realizados en un proyecto.

Podemos utilizar Git localmente sin necesidad de internet.

GitHub

GitHub es una plataforma en la nube que permite almacenar repositorios de Git y compartir proyectos.

Facilita el trabajo colaborativo entre varios desarrolladores.

2. Diferencias entre Git y GitHub

Git: registra los cambios y permite recuperar versiones anteriores.

GitHub: permite publicar los repositorios y colaborar en equipo.

Ejemplo práctico:

Creamos una página HTML, registramos sus cambios con Git y luego la compartimos mediante GitHub.

3. Comandos básicos de Git

Comando Función
git --version Verifica la versión instalada.
git init Inicializa un repositorio local.
git status Muestra el estado de los archivos.
git add . Prepara los cambios para un commit.
git commit -m "Avance" Registra los cambios preparados.
git log Muestra el historial de commits.
git branch Muestra las ramas locales.
git clone URL Copia un repositorio existente.
git push Envía commits al repositorio remoto.
git pull Obtiene e integra cambios remotos.

4. Conceptos importantes

Repositorio: lugar donde se almacenan los archivos de un proyecto y su historial de versiones.

Commit: registro de los cambios preparados en un momento determinado.

Branch: rama que permite desarrollar cambios de forma separada.

README.md: documento que explica el propósito y funcionamiento del proyecto.

.gitignore: archivo que indica qué archivos no rastreados debe ignorar Git.

5. ¿Cómo subir un proyecto a GitHub?

  1. Crear una carpeta con nuestro proyecto.
  2. Inicializar Git con git init.
  3. Preparar archivos con git add ..
  4. Registrar un commit con git commit.
  5. Crear un repositorio en GitHub.
  6. Conectar el repositorio local con GitHub.
  7. Subir los cambios con git push.
Importante: Git nos ayuda a llevar el historial del código, mientras que GitHub facilita compartirlo y trabajar en grupo.
