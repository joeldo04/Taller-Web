ECOSISTEMA RUNCTY

Todo conectado.
Un mismo proyecto.

RUNCTY es un proyecto que busca facilitar la planificación de rutas seguras para corredores en la ciudad de Loja. Para su desarrollo se proponen las siguientes tecnologías.

19 tecnologías
TecnologíaUso en el proyecto RUNCTY
TypeScriptLenguaje para desarrollar la web, la aplicación móvil y el servidor.
ReactPermite crear las interfaces de la página web y el panel administrativo.
ExpoFacilita el desarrollo de la aplicación móvil para Android.
Tailwind CSSAyuda a diseñar interfaces adaptables y mantener estilos uniformes.
Node.jsPermite ejecutar el código del servidor.
NestJSOrganiza la API REST y las funciones principales del sistema.
PostgreSQLAlmacena usuarios, rutas, reportes y otros datos del proyecto.
OpenStreetMapProporciona información de calles y caminos para los mapas de Loja.
MapLibrePermite visualizar mapas interactivos y recorridos de los corredores.
PrismaFacilita el acceso a la base de datos desde el servidor.
SupabaseServicio propuesto para alojar la base de datos en la nube.
VercelServicio propuesto para publicar la aplicación web.
RenderServicio propuesto para alojar el servidor de RUNCTY.
GitHubAlmacena el repositorio del proyecto y facilita el trabajo en equipo.
FigmaPermite diseñar los prototipos de la aplicación web y móvil.
GitControla los cambios realizados en el código del proyecto.
SwaggerPermite documentar y consultar los servicios de la API REST.
draw.ioPermite crear diagramas para representar el funcionamiento del sistema.
